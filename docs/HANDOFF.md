## 2. 定位、功能与架构

- 个人学习与生活工作台：今日安排、任务/事项、课内和课外学习、课表导入、笔记和附件、专注计时、习惯/提醒、个人记账、AI 助手。
- 技术栈（当前锁定源码）：Next.js 16.3.1 App Router、React 19.2.8、TypeScript 5.9.3、Zod 4；Node.js ≥22.13。使用现有锁文件，未经需求不要顺带升级。
- 页面主要在 `app/DashboardClient.tsx`，其他模块与纯逻辑放在 `app/`、`lib/`。经典/纸页两套样式可切换，默认纸页，支持页面颜色。
- 云端：Node 路由校验登录和权限；签名 HttpOnly 会话；Upstash Redis 保存空间状态，修订号和原子写入防止覆盖并行修改，保留最近 10 份写入前状态；Vercel 私有 Blob 存附件。
- AI：Vercel AI SDK + OpenAI-compatible 适配器调用 DeepSeek，当前源码固定官方地址及 `deepseek-v4-flash`；写入提案须经过预览/确认与版本校验。它与开发使用的 Codex 客户端是不同服务。
- `/preview` 使用演示数据，刷新会重置，不自动保存到真实云端。课表学习安排由客户端规则生成，不是后台定时器，也不自动读取本机 Obsidian。

## 4. 当前自动学习安排（最新需求）

2026-10-14 用户明确启用临时简短安排，替代此前课前、课上、课后三阶段规则；不再依据旧 Obsidian 方法生成学习说明。

- 听课只考虑会计学基础，其当天自动任务为“复习 · 科目”；其他科目为“自学 · 科目”。按当天课表的有效科目安排，每科每天一项、10–20 分钟，具体内容由用户决定，不生成明天预习、课堂任务、练题要求或单元总结。
- **排除科目**：跆拳道（包括“体育/跆拳道”）和气候与社会不自动安排自学。加载时清除这两科未完成且没有个人记录的自动待办，包含旧阶段、当前简短学习及延期项；有笔记、附件、投入时间或关联记录的项保留为独立学习资料，手动作业和已完成历史不动。
- 同科目当天多节课只生成一项；星期、学期起始日、教学周仍取现有课表。实际作业仍手动添加，任务/事项、学科折叠及长期阶段结构保留。自动节点时间沿用晚间默认值 `20:00`，可自行修改。
- 当前规则版本 **4**，键为 `study:日期:review:科目编号:日期`。规则变化保留删除/延期的去重标记；当天已有同科目的学习项（包括从其他日期延期来的项）会复用。完成、延期或删除不会自动再生成一项；只有明确重新安排且没有原项时才补齐。
- `migrateDailyStudyTasks` 在加载时处理未完成旧自动阶段：移除没有个人记录的过时/预先待办，将需保留的同科同日节点合并为简短学习项；保留附件、笔记、个人要求、成果和累计时间，并重连子任务及专注时间记录。保留显式延期、独立推进日及原截止日，已完成历史和手动作业不动。
- 合并若超过现有文本、附件或笔记容量，个人内容以独立“学习资料”保留，不截断或丢弃。无法关联科目的旧记录原样保留。旧方法字符串仅用于精确识别已生成的说明；个人改写不覆盖，不回灌恢复快照或清空云端空间。
